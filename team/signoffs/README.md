# Offer sign-offs

One file per buyer: `team/signoffs/<buyer_id>.md`. Append one line per review:

```
| player | time (UTC) | version | verdict |
| --- | --- | --- | --- |
| ville | 2026-10-29T10:30Z | v1 | fix: price below role minimum on slide 5 |
```

All four (rauno, ville, erika, panu) must appear. **The last of the four to sign off owns the offer** and handles submission, review and optimisation in the game (`docs/WORKFLOW.md`). Nobody submits before all four have signed.
